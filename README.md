# VibeCode Studio

Создай Hero-секцию для лендинга-портфолио специалиста по вайбкодингу. Используй визуальный стиль, цветовую палитру и композиционные решения загруженного референса.

Основной заголовок: Создаю AI-продукты через вайбкодинг

Подзаголовок: Быстро собираю MVP, лендинги и веб-приложения с помощью современных AI-инструментов

Разместить две основные кнопки с четкими акцентами:

Посмотреть проекты (светло-сиреневый акцент).

Связаться (темно-сиреневый акцент).

В правой части Hero разместить визуальный элемент — изображение мобильного телефона.

Обеспечить качественную адаптацию под мобильные устройства, сохранив читаемость и удобство взаимодействия. Остальное не трогай.
